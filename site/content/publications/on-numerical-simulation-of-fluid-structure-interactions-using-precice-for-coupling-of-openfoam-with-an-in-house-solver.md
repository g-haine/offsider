## Abstract
This paper describes numerical approximation of a fluid structure interaction problem. The interaction of the three dimensional turbulent fluid flow with vibrations of an elastic body are considered. The mathematical model of the problem is introduced. For numerical approximation of the elastic structure motion the Finite Element Method (FEM) is used whereas for the flow problem the Finite Volume Method (FVM) is employed. Mutual coupling of the two problems is considered and the preCICE numerical code is used for practical implementation of the coupled scheme. The structure dynamics is realized using an in-house C++ software and the flow is approximated using the OpenFOAM package. Verification of the in-house code is presented on several problems. Numerical results of flow-induced vibrations of a beam are presented.
