## Abstract
An efficient partitioned coupling algorithm for fluid-structure interaction problems is proposed in this paper. Partitioned coupling algorithms, which can treat a structural problem and a fluid dynamics one independently, seem suitable for large-scale computation in a parallel environment because they can utilize existing parallel analysis codes. In this paper, an iterative partitioned coupling algorithm with line search strategy is newly proposed to improve robustness, accuracy and efficiency. Performance of the proposed method is compared with that of Aitken extrapolation method.
